The file ```EC_results.txt``` contains the result of running ```NonsurjectivePrimes(E,100)``` for each elliptic curve E over a number field (not equal to Q) in the LMFDB. It is organized by LMFDB label. If a set of primes contains ```0```, then the algorithm was inconclusive, which was the case for all CM elliptic curves in the LMFDB. Moreover, by running Sutherland's algorithm (Andrew V. Sutherland, Magma scripts related to Computing images of Galois representations attached to elliptic curves,
available at http://math.mit.edu/~drew/galrep) on the lists in ```EC_results.txt```, one can confirm that there are no exceptional mod ell representations for any non-CM elliptic curves in the LMFDB beyond those already listed (whereas before, only the primes ell < 1000 were checked for each elliptic curve).
