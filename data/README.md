These files are the result of running ```ReduciblePrimes``` on all elliptic curves over number fields which are not Q in the LMFDB. Each entry consists of an ID number (an integer unrelated to LMFDB's label), a number field K (given as a polynomial), the coefficients of an elliptic curve in that number field (given as a list of elements K, using a formal symbol which depends on K), and a finite list of primes containing all primes ell where the mod ell representation is reducible **and ell is not a residue characteristic of bad reduction for E or ramified in K**. Adding in those finitely many primes will give a complete list. For entries where the algorithm failed to return an answer (such as in the case where the elliptic curve has CM over the base field), -1 is returned.
